Export legacy dashboard data

This tiny page reads your old Daily Dashboard data out of this browser's localStorage so you can import it into the new React+Supabase version.

  1. Make sure you're viewing this page at http://localhost:8080/legacy-export.html (same origin your old dashboard used).
  2. Click Copy to clipboard below.
  3. Paste it into the new app at Settings → Import legacy data.

Nothing leaves your browser from this page. The data is just sitting in localStorage under the key fs_user_data; this page only reads it.
